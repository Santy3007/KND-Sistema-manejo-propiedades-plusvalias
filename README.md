# KND-Sistema-manejo-propiedades-plusvalias

Proyecto académico desarrollado como parte de mis estudios, enfocado en la digitalización de procesos del sector inmobiliario mediante una plataforma web y una aplicación móvil.

## 📌 Antecedentes
El sector inmobiliario ha experimentado una transformación significativa gracias a los avances tecnológicos. La digitalización ha permitido optimizar la administración de propiedades, el acceso a la información y la comunicación entre agentes y clientes.  
Sin embargo, muchos sistemas existentes presentan limitaciones en integración, usabilidad y seguridad.

Este proyecto propone una solución integrada que unifica la gestión administrativa en una plataforma web y la interacción del cliente mediante una aplicación móvil.

## 🎯 Objetivo del proyecto
Desarrollar un sistema que permita:
- Gestionar propiedades de forma centralizada
- Coordinar citas entre agentes y clientes
- Simular créditos inmobiliarios
- Integrar una plataforma web y una app móvil mediante APIs REST

## 🧩 Problemática
- Falta de integración entre plataformas web y móviles
- Procesos manuales y duplicación de información
- Dificultad en la gestión de citas y simulaciones financieras
- Accesibilidad limitada desde dispositivos móviles

## 🛠️ Tecnologías utilizadas
- **Backend / Web:** PHP
- **App móvil:** Xamarin
- **Arquitectura:** API REST
- **Base de datos:** SQL Server / MySQL (ajustar según corresponda)
- **Entorno de desarrollo:** Visual Studio

## 📱 Funcionalidades principales
- CRUD de propiedades
- Gestión de citas
- Simulación de créditos inmobiliarios
- Autenticación de usuarios
- Integración web–móvil mediante API REST

## ⚠️ Nota
Este es un **proyecto académico**.  
No contiene datos reales ni corresponde a un sistema en producción.
